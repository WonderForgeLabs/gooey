# Generated clients for `gooey.control.v1`

Everything under `clients/` (and `grpc/gen/`) is generated by buf from
`proto/gooey/control/v1` and **committed** — regeneration is an
explicit act, run from the repo root:

```sh
go run github.com/bufbuild/buf/cmd/buf@v1.72.0 generate --template proto/buf.gen.yaml
```

Plugin versions are pinned in `proto/buf.gen.yaml`; CI fails on drift
(`buf generate && git diff --exit-code`), on lint, and on breaking
changes against `main`. Do not edit generated trees by hand — the
handwritten files are only the packaging (`pyproject.toml`,
`package.json`, `tsconfig*.json`, `src/index.ts` barrels, this file).

## Go — no registry, on purpose

The generated Go lives in the nested module
`github.com/WonderForgeLabs/gooey/grpc` (package `controlv1` at
`grpc/gen/gooey/control/v1`). It is consumed **via the git module path
like any Go module** — while the repo is private, set
`GOPRIVATE=github.com/WonderForgeLabs/*`. There is nothing to look for
in a package registry.

## Python — `gooey-control` (`clients/python/`)

Import package `gooey.control.v1`; distribution `gooey-control`;
runtime floors `protobuf>=7.35.1,<8`, `grpcio>=1.83.0`.

**Day-to-day consumption** (GitHub Packages has no PyPI index, so this
is the primary path):

```sh
pip install "git+https://github.com/WonderForgeLabs/gooey.git#subdirectory=clients/python"
```

**Tagged releases** are additionally pushed to GHCR as an OCI artifact
(wheel + sdist) at `ghcr.io/wonderforgelabs/gooey-control-python:<tag>`
by `.github/workflows/publish-clients.yml`. Fetch with oras, then pip
install the wheel:

```sh
oras pull ghcr.io/wonderforgelabs/gooey-control-python:v0.1.0
pip install gooey_control-*.whl
```

## TypeScript — two flavors (`clients/ts/`)

Both are published to the **GitHub Packages npm registry**
(`npm.pkg.github.com`, scope `@wonderforgelabs`) on `v*` tag pushes;
versions come from the git tag. Consumers need an `.npmrc` pointing the
scope at GitHub Packages with a token that can read packages:

```
@wonderforgelabs:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_TOKEN}
```

- **`@wonderforgelabs/gooey-control-connect`** (`clients/ts/connect/`):
  protoc-gen-es v2 schemas/descriptors; pair with `@connectrpc/connect`
  (+ `@connectrpc/connect-node`) to make calls.
- **`@wonderforgelabs/gooey-control-grpc`** (`clients/ts/grpc-js/`):
  protobuf-ts with `client_grpc1` — classic `@grpc/grpc-js` clients
  (`ControlServiceClient`, `SessionServiceClient`).

Committed code is TypeScript source; the publish workflow compiles
`dist/` (`npm run build`) before `npm publish`, so installed packages
carry JS + `.d.ts` alongside the source.
